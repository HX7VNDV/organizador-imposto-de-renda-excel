# Organizador para Declaração de Imposto de Renda

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de Excel, com o objetivo de criar uma ferramenta para centralizar e organizar informações importantes para a declaração de Imposto de Renda.

A solução funciona como um agregador de dados, permitindo registrar informações pessoais, informes de rendimentos, rendimentos recebidos, bens e direitos e pagamentos realizados.

## Funcionalidades

* Cadastro de dados pessoais
* Controle de informes de rendimentos
* Registro e classificação de rendimentos
* Controle de bens e direitos
* Registro de pagamentos
* Validações de dados e listas suspensas
* Navegação entre as áreas da planilha
* Consolidação automática das informações
* Checklist de preenchimento
* Dashboard com indicadores e gráficos

## Estrutura da planilha

### Início

Tela principal utilizada para navegação entre as diferentes áreas da ferramenta e acompanhamento do preenchimento.

### Dados Pessoais

Área destinada ao cadastro das principais informações do titular.

### Informes

Permite organizar os informes recebidos de bancos, corretoras, empregadores e outras instituições.

### Rendimentos

Área para registro dos rendimentos recebidos e dos respectivos impostos retidos.

### Bens e Direitos

Permite controlar informações patrimoniais e comparar os valores entre os períodos.

### Pagamentos

Área destinada à organização dos pagamentos e respectivos comprovantes.

### Resumo

Dashboard que consolida as principais informações cadastradas e apresenta indicadores para acompanhamento.

## Recursos do Excel utilizados

* Fórmulas e referências entre planilhas
* Validação de dados
* Listas suspensas
* Formatação condicional
* Tabelas estruturadas
* Fórmulas de soma e contagem
* Gráficos
* Links de navegação
* Formatação monetária
* Organização e consolidação de dados

## Como utilizar

1. Abra o arquivo `Organizador_Imposto_de_Renda_CORRIGIDO.xlsx`.
2. Utilize a aba INÍCIO para navegar pela ferramenta.
3. Preencha seus dados pessoais.
4. Cadastre os informes recebidos.
5. Registre os rendimentos.
6. Preencha as informações referentes aos bens e direitos.
7. Cadastre os pagamentos relevantes.
8. Consulte a aba RESUMO para visualizar os dados consolidados.

## Observação

Esta ferramenta possui finalidade exclusivamente organizacional e educacional. As informações devem ser conferidas antes de serem utilizadas na declaração oficial do Imposto de Renda.
